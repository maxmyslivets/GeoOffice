# Улучшения синхронизации проектов с помощью Watchdog

## Обзор

Данный документ описывает улучшения системы синхронизации проектов GeoOffice с использованием библиотеки `watchdog` для мониторинга файловой системы в реальном времени.

## Основные улучшения

### 1. Добавлена зависимость watchdog

- Добавлена библиотека `watchdog>=6.0.0` в `pyproject.toml`
- Обеспечивает эффективный мониторинг изменений файловой системы

### 2. Создан сервис мониторинга файлов

**Файл:** `src/services/file_watch_service.py`

#### Основные возможности:
- **Мониторинг в реальном времени** - отслеживание изменений файлов без периодического сканирования
- **Debouncing** - группировка событий с настраиваемой задержкой для предотвращения множественных вызовов
- **Фильтрация событий** - игнорирование временных файлов, системных файлов и файлов версионного контроля
- **Ограничение скорости** - предотвращение перегрузки системы при большом количестве событий
- **Детальное логирование** - отслеживание всех операций с файлами

#### Классы:

##### `ProjectFileHandler`
- Обработчик событий файловой системы
- Фильтрует события по типам файлов и паттернам
- Предотвращает дублирование событий
- Поддерживает debouncing

##### `FileWatchService`
- Основной сервис мониторинга
- Управляет наблюдателями файловой системы
- Предоставляет API для управления мониторингом
- Собирает статистику производительности

### 3. Интеграция с ProjectSync

**Файл:** `ProjectSync/project_sync.py`

#### Улучшения:
- **Автоматический мониторинг** - запуск мониторинга файлов при старте синхронизации
- **Быстрая синхронизация** - обработка изменений файлов без полного сканирования
- **Настройки мониторинга** - возможность включения/отключения мониторинга через GUI
- **Обработка событий** - специальная логика для разных типов событий файлов

#### Новые методы:
- `_handle_file_event()` - обработка событий файловой системы
- `_run_quick_sync()` - быстрая синхронизация для конкретных событий
- `_handle_new_project_file()` - обработка новых файлов проектов
- `_handle_deleted_project_file()` - обработка удаленных файлов проектов
- `_handle_moved_project_file()` - обработка перемещенных файлов проектов
- `_setup_file_watch()` - настройка мониторинга файлов
- `_stop_file_watch()` - остановка мониторинга файлов

### 4. Конфигурация мониторинга

**Файл:** `src/config/file_watch_config.py`

#### Настройки:
- **Паттерны игнорирования** - список файлов и директорий для игнорирования
- **Расширения проектов** - типы файлов для отслеживания
- **Настройки производительности** - параметры debouncing и ограничения скорости
- **Настройки логирования** - контроль детальности логирования

## Преимущества

### 1. Производительность
- **Мгновенная реакция** - изменения обрабатываются сразу после их возникновения
- **Эффективное использование ресурсов** - нет необходимости в периодическом сканировании
- **Ограничение нагрузки** - защита от перегрузки при большом количестве событий

### 2. Надежность
- **Фильтрация событий** - игнорирование нерелевантных файлов
- **Предотвращение дублирования** - защита от повторной обработки одних и тех же событий
- **Обработка ошибок** - корректная обработка исключений

### 3. Мониторинг
- **Детальное логирование** - полное отслеживание всех операций
- **Статистика производительности** - информация о скорости обработки событий
- **Настраиваемость** - гибкая конфигурация под различные сценарии использования

## Использование

### Запуск с мониторингом файлов

1. Запустите приложение ProjectSync
2. Настройте пути к серверу и базе данных
3. Включите опцию "Мониторинг файлов в реальном времени"
4. Запустите синхронизацию

### Настройка мониторинга

Можно настроить следующие параметры в `src/config/file_watch_config.py`:

```python
# Время задержки для группировки событий (секунды)
debounce_time = 2.0

# Максимальное количество событий в секунду
max_events_per_second = 10

# Включение/отключение детального логирования
log_file_events = True
log_ignored_events = False
log_performance_stats = True
```

## Логирование

### Уровни логирования

- **INFO** - основные события (создание, удаление, изменение файлов)
- **DEBUG** - детальная информация о фильтрации и обработке
- **WARNING** - превышение лимитов скорости
- **ERROR** - ошибки обработки событий

### Специальные логгеры

- `services.file_watch_service` - основной логгер сервиса
- `file_monitor` - специальный логгер для событий файловой системы

## Совместимость

- **Python 3.9+** - поддерживается всеми версиями Python 3.9 и выше
- **Кроссплатформенность** - работает на Windows, Linux и macOS
- **Обратная совместимость** - существующий функционал не изменен

## Заключение

Интеграция watchdog значительно улучшает производительность и отзывчивость системы синхронизации проектов GeoOffice. Мониторинг в реальном времени обеспечивает мгновенную реакцию на изменения файлов, а гибкая система конфигурации позволяет адаптировать поведение под различные сценарии использования.
